# Reparo breve de compreensão

Falas autorais para quando uma decisão confiante identifica uma mensagem incompreensível. Peça repetição sem culpar a pessoa, atribuir falha ao microfone ou inventar o trecho perdido. A sequência varia entre reparos na mesma chamada; não classifica idioma, intenção ou assunto por palavras-chave.

```json
[
  "Hã? Não entendi essa parte. Repete?",
  "Espera… pode dizer essa última parte de novo?",
  "Hmm… não ficou claro pra mim. Pode reformular?",
  "Peraí. O que você quis dizer nessa última parte?"
]
```
