# STT

Motor: faster-whisper, pt-BR, PCM mono de 16 kHz, duração entre 100 ms e 30 s. A transcrição acontece após o fim da fala; não há transcrição parcial nesta versão. O filtro VAD do Whisper complementa o detector simples do cliente.

Configuração, instalação e comandos estão em [Serviços locais](../README.md).
