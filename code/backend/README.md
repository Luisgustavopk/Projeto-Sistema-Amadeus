# Backend

- `api/`: base Fastify com autenticação, saúde, contratos HTTP e SQLite.
- `services/`: espaços reservados para transcrição (STT) e síntese (TTS).
- `assets/`: espaços para persona e perfis de voz.
- `evals/`: espaço para avaliações de persona, voz, latência e memória.

Apenas a base da API está implementada. Voz, memória e integração com provedores serão desenvolvidas conforme o plano.
